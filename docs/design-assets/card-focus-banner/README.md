# Card focus banner archive

Archived moving-tape focus banner explored for the card queue header. It used a fixed recessed aperture, a synchronized linear title tape, perspective side reveals, scale ticks, and scroll-linked expansion.

The experiment was removed from the live interface because its visual weight reduced the breathing room above the card deck. The source and final standalone styles remain here as a reusable design asset.

- `CardFocusBanner.tsx.txt`: archived React implementation. Rename to `.tsx` and restore its live imports before reuse.
- `card-focus-banner.css`: archived component styles.
